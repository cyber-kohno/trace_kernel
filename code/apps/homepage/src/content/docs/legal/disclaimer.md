# 免責・利用上の注意

このページは、Trace Kernelの利用に関する責任範囲と注意点の叩き台です。正式な公開前に、実装仕様と配布条件に合わせて内容を確定してください。

## 共通

Trace Kernelで実行するコード、登録するリソース、生成される出力、外部へのアクセス、ファイルの読み書きについては、利用者自身が内容を確認してください。

Trace Kernelは、作業を効率よく記述・実行するための環境を提供しますが、実行結果の正確性、業務適合性、外部システムへの影響、データ損失が発生しないことを保証するものではありません。

## ファイル操作

Pro版の`$fs` APIは、物理ファイルの読み書きや更新を行う機能です。

ファイルを更新する処理を実行する前に、対象パス、更新内容、バックアップの有無、実行権限を確認してください。

## 外部プロセス

Pro版の`process` contextは、ローカル環境上の外部プログラムを実行するための機能です。

実行するコマンド、引数、作業ディレクトリ、環境変数、対象ファイル、外部プログラム自体の安全性を確認してください。

外部プログラムの動作、ライセンス、出力結果、環境への影響は、当該プログラムの仕様と利用条件に依存します。

## ネットワークアクセス

Pro版の`$net` APIは、Webサイトや外部APIにアクセスするための機能です。

対象サイトの利用規約、robots.txt、API利用条件、レート制限、認証情報の扱い、法令や社内規程への適合を確認してください。

Trace Kernelは同一ドメインへの連続アクセスを抑制する仕組みを提供しますが、アクセス先の許諾や利用条件への適合を保証するものではありません。

## レートリミット解除

将来的に、`$net`のレートリミットを設定で解除できる仕組みを提供する場合があります。

その場合でも、アクセス頻度、対象サイトへの負荷、利用規約への適合については利用者自身が責任を持って確認してください。
