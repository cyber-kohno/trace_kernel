Pro機能を使うには、ライセンスキーでTrace Kernelをアクティベートします。

このページでは、ライセンスキーの購入と、Trace Kernelへの入力手順を整理します。

## 手順

1. ライセンスキーを購入する
2. Trace Kernelを開く
3. Settingsを開く
4. Licenseにライセンスキーを入力する
5. Activateを実行する
6. Pro機能が利用できることを確認する

> **画像メモ:** SettingsからLicense画面を開き、ライセンスキーを入力してActivateするまでのGIFがあるとよい。

## ライセンスキーの購入

[ライセンスキーを購入する](https://example.com/stripe-checkout)

> **メモ:** 上記URLは仮です。Stripe CheckoutまたはPayment Linkの本番URLが決まり次第、差し替えます。

## アクティベート後に使える機能

- ファイル操作
- 外部プログラム連携
- 共通ロジック
- `$fs`
- `$net`

## ライセンスキーの扱い

ライセンスキーは、購入者がPro機能を利用するためのキーです。

第三者へ共有せず、購入者本人が利用する環境で入力してください。

## うまくいかない場合

アクティベートできない場合は、次の点を確認してください。

- ライセンスキーの前後に空白が入っていないか
- ネットワーク接続が利用できるか
- すでに別の環境で利用上限に達していないか
- Trace Kernelを再起動しても状態が変わらないか

詳細なエラー表示や問い合わせ方法は、今後このページに追記します。
