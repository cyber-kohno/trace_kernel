このページは仮ページです。内容は今後追加します。

想定する流れ:

1. resourceにエクスポート対象ファイルのリストを登録する
2. datasetでコードベース全体を対象にする
3. リストに一致するファイルだけを抽出する
4. 元のフォルダ階層を保った出力先パスを組み立てる
5. `$fs`で必要なディレクトリを作成し、ファイルをコピーする
