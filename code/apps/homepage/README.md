# Trace Kernel Homepage

Astro + Starlightで構築するTrace Kernelのドキュメントサイトです。

## 方針

- まずStarlightの枠とMD編集体験を作る
- 内容は仮で置き、今後 `app` 配下の最新ソースを正として更新する
- ほとんどをMarkdownで管理し、必要な箇所だけMDXを使う

## 起動

```bash
npm install
npm run dev
```

## 主な編集場所

- `src/content/docs/index.mdx`
- `src/content/docs/overview/`
- `src/content/docs/guide/`
- `src/content/docs/reference/`
- `src/content/docs/recipes/`

スクリーンショットは `public/screen_shot/` に置いています。
