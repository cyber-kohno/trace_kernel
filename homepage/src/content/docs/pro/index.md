---
title: Pro版とは
description: Trace Kernelの外側へ作用する高度な操作。
---

Trace Kernelの標準機能は、リソースを読み、TypeScriptで解析し、結果を画面に出力するところで完結します。

Pro版では、その範囲を広げます。外部プログラムを呼び出す、物理ファイルを作成・更新・削除する、共通ロジックを複数のworkから再利用する、といった操作を扱えます。

標準機能が「読む、解析する、出力する」ための環境だとすれば、Pro版は「外部へ作用する」ための環境です。

## 拡張されること

| 領域 | できること |
| --- | --- |
| ファイル操作 | ファイルの作成、更新、削除、リネーム、コピー |
| 外部プログラム | ローカルの補助ツールや変換処理をworkから呼び出す |
| 共通ロジック | 複数のworkで使う処理をlogicとして定義する |

## 注意すること

Pro機能は、Trace Kernelの外側にあるファイルやプログラムへ作用します。

そのため、標準機能よりもできることは増えますが、同時に誤った処理の影響も大きくなります。ファイル更新や外部プログラム連携では、対象、入力、出力、実行結果を確認しながら使うことが前提になります。

> **画像メモ:** 標準機能の「resourceを読む、結果を出す」と、Pro機能の「外部プログラムを呼ぶ、ファイルを更新する」を左右で比較する図があるとよい。

## Pro機能の位置づけ

Pro版は、標準機能を使えないと成立しない別アプリではありません。

標準機能でリソース解析や出力確認ができるようになった上で、作業の最後にファイルへ反映したい、外部ツールを組み込みたい、処理を共通化したい場合に使う拡張領域です。

Pro機能を利用する場合は、[アクティベート](/pro/activate/)でライセンスキーの購入と入力手順を確認してください。
