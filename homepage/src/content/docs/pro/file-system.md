Pro版では、workからファイルシステムを操作できます。

標準機能では、解析結果を画面に出力し、必要な結果をコピーして利用します。Pro版では、処理結果をファイルとして保存したり、既存ファイルを更新したり、複数ファイルをまとめて整理したりできます。

## 主な用途

- 解析結果からファイルを生成する
- 複数ファイルの内容を一括更新する
- ファイル名をルールに従ってリネームする
- ディレクトリを作成する
- 不要なファイルを削除する

## トランザクション

ファイル変更は強力ですが、失敗したときの影響も大きくなります。

Trace Kernelでは、ファイル操作をすぐに実ファイルへ反映せず、変更内容を確認してからコミットするためのトランザクション機構を提供します。

```ts
const tx = $fs.useTransaction();

const { token, content } = await tx.openText(`${$env.DIR}\\target.txt`, 'utf8');
tx.updateText(token, content.replaceAll('old', 'new'));
```
