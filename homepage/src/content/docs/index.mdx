Trace Kernelは、TypeScriptで「書く」「実行する」「結果を見る」をひとつのアプリ上で完結させるためのデスクトップ実行基盤です。

アプリ開発のためのプロジェクトを作るのではなく、ログ分析、データ加工、ファイル整理のような小さな問題をすぐに解くことを主眼に置いています。

<CardGrid>
  <Card title="環境構築なしで書く" icon="seti:typescript">
    プロジェクト作成、依存関係、実行用ターミナルを意識せず、アプリ内のMonacoエディタでTypeScriptを書きます。
  </Card>
  <Card title="リソースをGUIで管理する" icon="seti:folder">
    env、resource、dataset、processをワークスペースに登録し、スクリプトへ型付きで注入します。
  </Card>
  <Card title="結果をアプリ内で見る" icon="seti:json">
    テキスト出力、チャンネル出力、テーブル出力、進捗表示をGUI上で確認できます。
  </Card>
  <Card title="ファイル操作を安全に確認する" icon="seti:lock">
    トランザクションAPIにより、仮想FS上で変更内容を積み、確認後に実FSへ反映できます。
  </Card>
</CardGrid>
