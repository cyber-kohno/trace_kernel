# 利用規約・ライセンス

このページは、Trace Kernelの利用条件とライセンスに関する叩き台です。正式な公開前に、配布形態、販売方法、同梱物、利用許諾の範囲に合わせて内容を確定してください。

## Trace Kernelの利用

Trace Kernelは、技術者がTypeScriptで作業を記述し、実行し、結果を確認するためのデスクトップアプリです。

無料版は、利用者の業務や個人作業で利用できます。Pro版は、ライセンスをアクティベートすることで追加機能を利用できます。

## 業務利用

Trace Kernel自体は、業務上の調査、解析、変換、確認作業に利用できます。

ただし、Trace Kernel上で扱うデータ、実行するコード、連携する外部ツール、アクセスする外部サービスについては、それぞれの利用条件、契約、ライセンス、社内規程に従ってください。

## Proライセンス

Pro版の利用には、有効なライセンスキーが必要です。

ライセンスキーの共有、再配布、貸与、第三者への譲渡については、正式なライセンス条件で定義します。

## 外部ソフトウェアとの連携

Trace Kernelの`process`機能などを使って外部CLI、OSSツール、商用ツールを実行する場合、そのツールの利用条件やライセンスはTrace Kernelとは別に適用されます。

たとえば、OSSのCLIを呼び出して解析や変換を行う場合、当該OSSのライセンス、再配布条件、商用利用条件、出力物の扱いを利用者自身で確認してください。

## 同梱ライブラリとOSSライセンス

Trace Kernelが同梱または利用するOSSライブラリのライセンス表記は、正式公開前に一覧化します。
