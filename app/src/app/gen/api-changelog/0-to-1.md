# API 0 -> 1

API generation `0` to `1`.

## Breaking Changes

- DOM parser node type was renamed from `XmlNode` to `DomNode`.
- This affects both `$parser.xml(...)` and `$parser.html(...)`.
- Existing explicit type annotations such as `const node: XmlNode = ...` will fail after opening the workspace with the new app.

## Migration Example

```ts
const controller = await $parser.html(source);
const node: DomNode | null = await controller.root();
```

Replace explicit `XmlNode` annotations with `DomNode`.
