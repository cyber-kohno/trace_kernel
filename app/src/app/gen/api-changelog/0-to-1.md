# API 0 -> 1

API generation `0` から `1` への変更点です。

## Breaking Changes

- `process` function now supports `cwd`.
- `process` function now supports `stdin`.
- `workspace` file stores `gen.workspace` and `gen.api`.

## Migration Example

```ts
const result = await $process.sample('arg');
```

このドキュメントはダミー表示です。後で実際の変更内容に差し替えます。
