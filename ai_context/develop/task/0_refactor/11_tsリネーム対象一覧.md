# `.ts` リネーム対象一覧

## 対象抽出ルール

次のいずれかに該当する `.ts` を対象とする。

- PascalCase を含む
- camelCase で単語連結している
- typo を含む
- 既存命名規約の `kebab-case` に反している

## 着手順の推奨

1. Wave 1 を実施する
2. `npm run check`
3. Wave 2 を実施する
4. `npm run check`
5. Wave 3 以降を段階的に進める

最初の実作業としては、store 配下の rename から入るのが最も効果が高い。
