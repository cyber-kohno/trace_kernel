このページでは、Trace Kernelのリリースごとの変更点を記録します。

各リリースには、`App Version`、`API Gen`、`Workspace Gen`を記載します。更新時は、追加機能や修正内容だけでなく、API互換とワークスペース互換への影響も確認してください。

## v0.9.0

| 項目 | 値 |
| --- | --- |
| API Gen | 33 |
| Workspace Gen | 19 |
| リリース日 | 2026/05/14 |

### 変更内容

- ベータ版公開に向けた仮エントリです

### API互換への影響

- API Genが`32`から`33`に上がる想定です
- 具体的な変更内容は、リリース時に記載します

### ワークスペース互換への影響

- Workspace Genは`19`です
- 古いWorkspace Genの`.trk`ファイルは、自動マイグレーション対象です
